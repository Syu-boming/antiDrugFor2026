反毒剪紙劇場｜許博明老師製作
先深呼吸：畫面一定停在某個停格點等老師，不會自己亂跳；播放中多按的鍵會被忽略。學生照常坐著，老師可以先帶大家說一次口訣「不碰、不試；先離開，找大人。」
症狀第一個動作還不行（退路）
簡報筆按了沒反應看控制台上方「焦點」：點一下控制台（或舞台）任何地方取回焦點。檢查 USB 接收器與電池。用筆電鍵盤：PageDown 或 →＝下一步、空白鍵＝暫停；或按控制台的「下一步」。換備用簡報筆。鍵碼不同時用控制台「按鍵測試」設定。
沒有聲音看控制台「聲音」狀態。檢查 Windows 播放裝置（接投影機後常被改成 HDMI）、音量、場地擴音與音源線。按黑屏鍵暫停再繼續。第一個字被吃掉：教師選單（M）「開頭靜音」改 200 或 400。仍沒聲音：老師照字幕與講稿講述，劇情照常進行。
畫面卡頓、不順等這一段播完停住。在停格時按 M → 畫質「B 級」或「鎖 30 fps」，再按 M 關掉選單。關掉其他程式、插電、高效能模式。仍卡：改用備援影片（下方）或紙本題卡。
出現「畫面暫停」或「顯示卡連線中斷」按一次「下一步」，重新建立畫面，回到目前的停格點。重建失敗：關掉程式重開，用控制台「跳到」選講稿上的 cue 編號、按「前往」。授課時鐘會保留。
畫面黑掉、被重新整理或程式關掉不用慌：舞台回到「準備播放」畫面，不會自己出聲。按「準備播放」，再用控制台「跳到」回到剛才的 cue。程式關掉了：重新雙擊 AntidrugTheater.exe，同上跳回。
螢幕被關掉或系統休眠喚醒後畫面停在原處，按黑屏鍵（或下一步）繼續，不會跳段。—
只有一個畫面、控制台被投影出去按 Win＋P 選「延伸」。控制台會提示改用單一舞台視窗：只用舞台和簡報筆演出，看紙本講稿。
控制台顯示「舞台：未連線」點一下舞台視窗，等 2–3 秒。只用舞台視窗演出（M 鍵選單可跳段），看紙本講稿與 cue 編號。
投影機沒畫面或故障檢查訊號線與投影機的輸入來源；Win＋P 重選「延伸」。改用紙本題卡完成八題（題卡_學生版.pdf，可放大印成 A3），老師照講稿說故事。
準備播放是灰的、停在「資料包 n／m」看畫面上寫的原因。關掉程式，把整個交付資料夾重新複製到本機硬碟再開。改開瀏覽器版或備援影片（下方）。
Windows 擋執行檔（「Windows 已保護您的電腦」）按「其他資訊」→「仍要執行」（學校允許時）。學校電腦禁止執行時，請資訊組協助，或改用瀏覽器版（下方）。

瀏覽器版怎麼開：用 Chrome 或 Edge 開啟 browser\index.html（不用加參數，預設就是全劇），按「準備播放」，用簡報筆操作。要雙畫面：開 browser\console.html，按「開啟舞台視窗」，把舞台拖到投影畫面，在舞台上按一次「準備播放」。不需要網路、不用安裝。

備援影片怎麼播：用 Windows「媒體播放器」依序開 backup_a0.mp4 → … → backup_a8.mp4，全螢幕；Win＋P 選「同步顯示」。出題停 3 秒時按筆電空白鍵暫停，揭答說完再按空白鍵繼續；暫停點見 README.txt。
