# 教師與學校資料（G7 交付：教師資料、學校資料、列印檔、PDF 題卡）

反毒剪紙劇場《紙燈節》｜許博明老師製作

這個資料夾的東西都由一支腳本依演出資料產生。cue（`app/cues/show/*.json`）、配音、八題定稿改了之後，重跑一次就會全部更新，包括時間、題目文字與檢查報告。

## 一鍵重建

在專案根目錄執行：

```bash
node tools/teacher_docs.mjs              # 全部重建：Markdown、HTML、PDF、檢查報告（圖已存在就沿用）
node tools/teacher_docs.mjs --art        # 連貼紙、小卡用的角色圖一起重做（從 assets 母版裁切、折折重新渲染）
node tools/teacher_docs.mjs --no-pdf     # 只產生 Markdown 和 HTML，不開 Chrome
node tools/teacher_docs.mjs --only 教師講稿,題卡_學生版   # 只重印指定的 PDF（名稱同 html/ 的檔名）
```

- 需要：Node 24、本機 Google Chrome（Playwright 的 `channel: 'chrome'`，用 `app/node_modules` 裡的 playwright-core 與 esbuild）、ffprobe、pdftotext／pdfinfo（Homebrew poppler）。
- 執行時間約 10 秒。結束訊息會列出預估總長、題目比對與檢查結果；有題目不一致或檢查不通過時，結束碼是 1。
- 腳本只讀 `app/`、`script/`、`assets/`、`audio/`，不改任何演出檔。

## 自動檢查（每次重建都跑）

- **八題文字**：cue 的 `quiz` 和 `script/八題_v03.md` 的題卡文字一字不差；旁白念的題幹與「一，」「二，」「三，」選項、揭答句、正解（2、3、1、1、3、2、3、2）、指定區（A→B→C→D 各輪兩次）都比對；再用 pdftotext 從印出來的兩份 PDF 題卡抽字，確認每一頁都有該題的題目與三個選項。
- **用語**：不出現藥名、貶稱（毒蟲、廢人）；法規分級與刑度不進兒童列印檔，教師資料只出現在「不談」的說明；「喪屍」只指物品或用在「人不會變成喪屍」；不把操偶線叫成「灰線」；常見簡體字與大陸用語掃描；每份都有「許博明老師製作」。
- **必要旁白**：兩句必要旁白在 cue 檔一字不差。
- **PDF**：頁數符合（操作卡、故障卡、導覽單、回饋單、小卡各 1 頁；題卡學生版 8 頁、教師版 9 頁；貼紙、成果紀錄各 2 頁），圖都載入，字型是 Noto Sans TC。
