## 數字（取自 metrics.json）

| 項目 | 結果 |
|---|---|
| 格式 | 48 kHz／16-bit PCM；配樂立體聲、音效單聲道 |
| 底樂（劇情襯底段組，10 首） | 全部 −24.0 LUFS；組內差距 0.0 LU（loudness_decision 第 (3) 層 ≤ 2 LU：通過） |
| 主奏段組（開幕、閉幕、謝幕） | 全部 −20.0 LUFS；組內差距 0.0 LU |
| 素材檔偏離目標 | 全部 0.0 LU（第 (1) 層 ≤ ±1 LU：通過） |
| 真峰值 | 新配樂最高 −6.6 dBTP（music_zhezhe；G3 閉幕曲 −5.8）；新音效最高 −12.0 dBTP；全部 ≤ −2 dBTP |
| 新配樂 100 ms 內最大跳升 | 0.8–5.8 dB（最大：music_courage 5.8 dB 在 25.1 s 木琴回聲、music_zhezhe 5.7 dB 在循環回到短句）；沒有用限制器 |
| 循環接縫（新配樂 7 首） | 首尾樣本差 17–180 LSB，都小於該檔相鄰樣本差的 99.9 百分位（425–1793 LSB）；接兩遍時接縫處瞬間響度跳升 0.8–5.7 dB |
| 循環接縫（環境聲 4 個） | 首尾樣本差 4–12 LSB；接縫處瞬間響度跳升 1.8–3.7 dB |
| music_shiny 低頻 | 100 Hz 以下能量 −95 dB（最低音 C4、高通 200 Hz：沒有低頻轟鳴） |
| 新音效起音 | 全部 ≥ 5 ms；最短是竹篾 6.0、手錶 6.2、腳步 7.0 ms（量法：1 ms 包絡從峰值 −40 dB 升到 −6 dB） |
| 新音效音量 | 一次性的最大瞬間響度 −24～−31 LUFS；環境聲整合響度：風 −30、廣場人聲 −34、校門口 −36、電話底音 −38 LUFS（對白 −18） |
| 救護車引擎 | 開近段 1 秒內最大上升 7.3 dB、100 ms 內 2.6 dB；沒有警笛、喇叭、煞車聲 |

一次性音效從靜音起音時，「100 ms 內跳升」是從 −50 LUFS 下限算起（14–26 dB），絕對音量都不超過 −24 LUFS，不是巨響；這個算法和 G3 相同。

## 安全界線對照（設計上做到的；聽感未驗證）

- 沒有答對／答錯音效、沒有抖動或晃動聲效、沒有驚嚇音、沒有突發巨響；救護車沒有警笛；電話底音與手錶撥號音不是任何電信業者的音調（不用 DTMF、回鈴音、忙線音）。
- 人聲遠景（廣場、校門口）只用母音共振峰合成，沒有子音，多人重疊、低通、加殘響 → 聽不出任何字；也沒有配音念藥名的問題。
- M3 閃亮動機：中高音域、沒有低頻轟鳴、不恐怖。M5：重音 3+3+2，不是時鐘滴答，也沒有警報式的高音重複。
- 下課鐘用西敏寺鐘聲（1793 年旋律，公有領域）前兩句，柔和音色。全部素材自製，沒有用來源不明的錄音或音樂。
