# 反毒剪紙劇場《紙燈節》｜使用說明

許博明老師製作。

這份是交付資料夾裡唯一的使用說明，取代 10:10 的舊版「使用說明_初步完成說明」。內容以 `teacher_pdf/` 的「一頁操作卡」「故障一頁卡」為準，數字和 `總報告.md` 一致。

---

## 一、這是什麼、現在做到哪裡

- 國小三、四年級約 110 人、一節 40 分鐘的剪紙劇場，主題「喪屍煙彈、毒駕」。
- 老師用簡報筆一步一步推進；八題三選一，學生比 1、2、3 手指，老師判定。
- 片頭署名卡「許博明老師製作」→ 布幕打開 → 開場、第一到第六幕、複習、謝幕 → 布幕合上，停在同款署名卡。
- 全劇 71 段（cue）、201 句配音，每句都有繁體字幕。
- 八題正解依序：**2、3、1、1、3、2、3、2**。

| 時間 | 長度 |
|---|---|
| 預錄播放 | **22 分 02 秒**（71 段 cue 長度合計）；加上換景時的漸暗預捲（全劇 10.8 秒）約 **22 分 13 秒** |
| 加上教師說明與作答 | 約 **35 分 45 秒**（上限 38 分，緩衝 2 分 15 秒） |

- 兩個預錄數字是同一件事的兩種算法：教師講稿的時間總表寫 22 分 02 秒（cue 合計），預捲的 10.8 秒算在講稿「按鍵與換景 1 分 27 秒」裡；本檔與總報告寫的「約 22 分 13 秒」是含預捲的數字。總長 35 分 45 秒在講稿、本檔、總報告都相同＝預錄播放 22 分 02 秒＋教師時間 12 分 16 秒＋按鍵與換景 1 分 27 秒。

**驗收進度**

| 關卡 | 結果 |
|---|---|
| G1 劇本～G5 各幕 | 都已通過（部分帶一般問題放行） |
| G6 全劇 | 通過，帶一般問題放行（重驗兩位都沒有嚴重問題） |
| G7 交付 | **通過，帶一般問題放行**（修正兩輪後沒有嚴重問題；細節見 `總報告.md` 1.2 與 5.7） |

詳細的驗收紀錄、代理替您做的決定、已知問題，都在 `總報告.md`。

## 三、怎麼開

### A. Windows 可攜版（首選）

1. 筆電插電，設成高效能模式，關掉通知與自動更新。
2. 接投影機與場地音響，按 **Win＋P** 選「**延伸**」。確認 Windows 的播放裝置是場地音響。
3. 雙擊 `AntidrugTheater\AntidrugTheater.exe`。
   - 投影上出現舞台。
   - 筆電上出現深色大字的「教師控制台」。
4. 在控制台按一次「下一步」＝**準備播放**（同時啟用聲音）。
5. 畫面停在「許博明老師製作」署名卡。之後**不再動滑鼠**，改用簡報筆。

補充：

- **只有一個畫面**（同步顯示）時，會自動只開舞台。用簡報筆照常演；M 鍵是教師選單。
- 出現「**Windows 已保護您的電腦**」：學校允許時按「其他資訊」→「仍要執行」。學校不允許時，請資訊組協助，或改用瀏覽器版。不要自己想辦法繞過學校規定。
- 按「準備播放」時若出現「缺幾句配音」的提示：表示複製時漏了檔，請重新複製整個資料夾。

### B. 瀏覽器版（第一層備援）

| 用法 | 怎麼開 |
|---|---|
| 只開舞台 | 用 Chrome 或 Edge 開 `browser\index.html`。**不用加任何參數，就是全劇。**按「準備播放」，用簡報筆操作 |
| 雙視窗（舞台＋控制台） | 開 `browser\console.html` → 按「開啟舞台視窗」→ 把舞台視窗拖到投影畫面 → 在舞台上按一次「準備播放」 |

- 不需要網路，也不用安裝。建議彩排時先開好並加入書籤。
- 舊資料寫「網址最後加 `?cues=show`」。現在加不加都一樣，都是全劇。

### C. 線上版（只做預覽）

- 網址：https://syu-boming.github.io/antiDrugFor2026/
- 只用來在家預覽、練習。
- **正式演出一律用離線版**（A 或 B）。理由：兒童安全界線第 11 條「演出完全離線」。

## 四、簡報筆與鍵盤

| 按鍵 | 動作 |
|---|---|
| 簡報筆「下一頁」（PageDown；鍵盤 → 也可以） | **下一步**。播放中多按會被忽略，不會跳段 |
| 簡報筆「上一頁」（PageUp） | 回上一個停格點（穩定節點） |
| 簡報筆「黑屏鍵」（句點） | 暫停／繼續 |
| 空白鍵 | 暫停／繼續（鍵盤備用） |
| 簡報筆「放映鍵」（F5／Esc） | 已攔截，不會跳出 |
| R | 重播這一段 |
| M | 教師選單（跳段、畫質、聲畫偏移）。會出現在投影上；雙畫面時改用控制台的「跳到」 |

- 羅技簡報筆實際送出的鍵碼，要用控制台的「按鍵測試」或 `browser\keytest.html` 確認。鍵碼不同時，可以在那裡改設定。
- 每一題的流程、八題看哪區、時間落後怎麼壓縮：看 `teacher_pdf/一頁操作卡.pdf`。

## 五、出狀況怎麼辦

**先深呼吸**：畫面一定停在某個停格點等老師，不會自己亂跳。學生照常坐著，老師可以先帶大家說一次口訣「不碰、不試；先離開，找大人。」

| 症狀 | 第一個動作 | 還不行（退路） |
|---|---|---|
| **沒有聲音** | 看控制台的「聲音」狀態。檢查 Windows 播放裝置（接投影機後常被改成 HDMI）、音量、場地擴音與音源線 | 按黑屏鍵暫停再繼續。第一個字被吃掉：M 選單「開頭靜音」改 200 或 400。仍沒聲音：老師照字幕與講稿講述，劇情照常進行 |
| **簡報筆失靈** | 看控制台上方「焦點」，點一下控制台（或舞台）任何地方取回焦點。檢查 USB 接收器與電池 | 改用筆電鍵盤：PageDown 或 →＝下一步、空白鍵＝暫停；或按控制台的「下一步」。換備用簡報筆 |
| **畫面卡頓、不順** | 等這一段播完停住。停格時按 M → 畫質選「B 級」或「鎖 30 fps」，再按 M 關掉選單 | 關掉其他程式、插電、高效能模式。仍卡：改用備援影片或紙本題卡 |
| **「畫面暫停」或「顯示卡連線中斷」** | 按一次「下一步」，重新建立畫面，回到目前的停格點 | 重建失敗：關掉程式重開，用控制台「跳到」選講稿上的 cue 編號，按「前往」。授課時鐘會保留 |
| **畫面黑掉、被重新整理或程式關掉** | 舞台回到「準備播放」畫面，不會自己出聲。按「準備播放」，再用控制台「跳到」回到剛才的 cue | 程式關掉了：重新雙擊 `AntidrugTheater.exe`，同上跳回 |
| **螢幕關掉或系統休眠** | 喚醒後畫面停在原處，按黑屏鍵（或下一步）繼續 | — |
| **只有一個畫面、控制台被投影出去** | 按 Win＋P 選「延伸」 | 只用舞台和簡報筆演出，看紙本講稿 |
| **控制台顯示「舞台：未連線」** | 點一下舞台視窗，等 2–3 秒 | 只用舞台視窗演出（M 選單可跳段），看紙本講稿 |
| **畫面寫「無法開始：缺少…」，或按鈕寫「仍要播放（缺 N 句配音）」** | **不要再按**（再按一次會在缺配音的情況下開演）。看舞台畫面上寫的原因（缺哪個檔、缺幾句配音），關掉程式，把**整個交付資料夾**重新複製到本機硬碟再開 | 改開瀏覽器版（第三節 B）或備援影片（下面） |
| **程式完全打不開、當掉救不回來** | 改用瀏覽器版（第三節 B） | 再不行：改播**備援影片**（下面） |
| **投影機沒畫面或故障** | 檢查訊號線與投影機的輸入來源；Win＋P 重選「延伸」 | 改用**紙本題卡**完成八題（`teacher_pdf/題卡_學生版.pdf`，可放大印成 A3），老師照講稿說故事 |

**退路順序**（一層不行就換下一層）：

Windows 可攜版 → 瀏覽器版 → 備援影片 → 紙本題卡＋講稿

### 備援影片怎麼播

詳細步驟與「哪裡要暫停」的時間表，在 `backup_video/README.txt`。

1. 確認 `backup_video` 資料夾已經在筆電本機硬碟上。
2. 按 Win＋P 選「**同步顯示**」（影片只有一個畫面，同步最簡單）。
3. 在影片上按右鍵 →「開啟檔案」→ 選「媒體播放器」（Windows 11）或「電影與電視」（Windows 10）。
4. 按播放器右下角的全螢幕鈕。離開全螢幕按 Esc。
5. 暫停／繼續：按**筆電的空白鍵**。簡報筆的翻頁鍵在播放器裡不一定能暫停。
6. 一段播完，開下一個檔案：a0 → a1 → … → a8。最後停在「許博明老師製作」署名卡。

| 檔案 | 段落 | 長度 |
|---|---|---|
| backup_a0.mp4 | 開場 | 02:04 |
| backup_a1.mp4 | 第一幕（Q1） | 02:52 |
| backup_a2.mp4 | 第二幕（Q2、Q3） | 04:50 |
| backup_a3.mp4 | 第三幕（Q4） | 02:46 |
| backup_a4.mp4 | 第四幕（Q5、Q6） | 04:06 |
| backup_a5.mp4 | 第五幕（Q7） | 03:14 |
| backup_a6.mp4 | 第六幕（Q8） | 03:26 |
| backup_a7.mp4 | 複習 | 00:54 |
| backup_a8.mp4 | 閉幕 | 00:39 |

- **從中途接**：看講稿或控制台上目前的 cue 編號（例如 a4_c009），開那一幕的檔案，照 `README.txt` 第四節表格的時間拖曳進度列。
- 影片沒有互動：答題、說明、發獎都要老師自己按暫停。每段播完會停 2 秒，出題畫面停 3 秒，就在這時候按暫停。

## 七、還沒驗證、要在學校實測的事

這些事代理（AI）做不到，只能請許老師在學校確認。逐項檢查表在 `總報告.md` 第八節。

| 項目 | 為什麼還沒驗證 | 怎麼確認 |
|---|---|---|
| 硬體探針 | 結果還沒回來 | 在學校筆電跑 `AntidrugProbe_v01`，把結果檔傳給 Claude |
| Windows 可攜版（exe） | 從沒在 Windows 實機跑過，只在 Mac 測過 | 雙擊 `AntidrugTheater.exe`，看能不能進到署名卡 |
| SmartScreen／學校應用程式控制 | 查不到學校的設定 | 看會不會出現「Windows 已保護您的電腦」、有沒有「仍要執行」 |
| 羅技簡報筆鍵碼 | 碰不到實體簡報筆 | 控制台「按鍵測試」或 `browser\keytest.html` |
| 聽感 | Claude 聽不到聲音；配音加配樂、音效的完整混音沒有人聽過 | 坐最後一排完整聽一次；聽不清的句子記下 cue 編號 |
| 最後一排的畫面 | 只用程式模擬過投影 | 從最後一排用手機拍題卡、字幕、操偶線段各一張 |
| 學校筆電的效能與耐熱 | 只在開發機量過（開到署名卡 7.5 秒、播放順暢） | 開演前 30 分鐘開好，完整播一次，注意換景會不會頓 |
| 備援影片播放器 | 沒在學校筆電試過 | 課前開一次 `backup_a0.mp4`：有畫面、有聲音、空白鍵能暫停 |
| 40 分鐘實際計時 | 35 分 45 秒是估算 | 彩排時開碼錶，記下實際總長 |
