## 2. 方法

**篩選（不計點）**：候選篩選（只用客觀條件，不含聽感）：硬條件＝台灣華語（locale／verified_languages）、Starter「你好」實測可用、計費倍率 1、性別與年齡符合角色表、用途條件（旁白與執勤人員限 narrative_story／informative_educational）、成人寫實角色排除 characters_animation、邀請者預覽 F0 在中性區 145–175 Hz、兒童角色預覽 F0 ≥ 220 Hz；排序＝聲線主人預覽檔的 F0 中位與 casting.json 的 F0 目標相差的半音數（小者優先），取前 3。同一個聲線可以同時是不同角色的候選（各角色獨立篩選）。

**合成**：每個角色最多 3 個候選，各念 2–3 句該角色的劇本台詞（`vo_lib.load_lines()` 依台詞編號讀，一字不改；替身字照 `audio/vo/pronounce.json` 的全域表，與正式管線相同），另外補念所選台詞沒涵蓋的檢查詞片段（取自同一角色的台詞）。eleven_multilingual_v2；voice_settings：stability 0.5、similarity_boost 0.75、style 0、use_speaker_boost true、speed 依角色（表內列出）；seed 20261021；mp3_44100_128。eleven_v3：stability 0.5、similarity_boost 0.75、speed 同上、language_code zh。
- 必要旁白一 a2_c004_02：依句號分三段合成、speed 0.85，段間插入 1,300 ms 靜音（沿用 vo_lib.split_breaks／vo_build.plan_segments 的分段方式；每段修到語音起訖前 10 ms、後 80 ms，10 ms 淡入／20 ms 淡出），量到的句間停頓與 edge 版（1.41 秒）比較。
- eleven_v3 的 API 接受 speed 參數（沒有任何錯誤回應、沒有不帶 speed 重試）；是否生效沒有另外測，實測語速見比較表。
- 執勤人員：與 edge 基準相同的 300–3400 Hz 電話音色（casting.json post.telephone）。ElevenLabs 候選不做句中停頓上限（max_pause_ms），保留合成器原本的停頓。
- **edge 基準**：照 `audio/vo/casting.json` 目前參數（含 post：替身字、[[break]]、segment_rates、contour、max_pause_ms、sentence_gap_ms、telephone）走 `vo_build.render_line` 念同樣的句子（免費）；原始檔快取放在本資料夾 `raw_edge/`，不寫 `audio/vo/_raw/`。
- **母帶**（同 G3，`vo_lib.master`）：去頭尾靜音後補頭 120 ms、尾 250 ms；−18 LUFS；真峰值 ≤ −1.5 dBTP；48 kHz／16-bit／單聲道（TPDF 抖動，固定亂數種子）。

**量測**：每個樣本（母帶後 48 kHz／16-bit）的量測：vo_lib.measure（整合響度、真峰值、削波、頭尾靜音、毛語速＝字數÷語音區間、淨語速＝扣掉 ≥250 ms 停頓、rate_cps_net_r＝驗收者算法（−40 dB、≥200 ms）、句中停頓 pauses_ms（−35 dB、≥150 ms）、F0 中位與 p10–p90）＋共振峰（有聲格 LPC Burg，上限 5500 Hz）＋兩個轉寫模型（faster-whisper small、large-v3-turbo）的 CER／PER 與檢查詞（vo_lib.compare：逐字對齊；參考讀音取合成用文字；台灣讀音表）。raw_*_silence_ms＝合成器原始檔頭尾靜音。

- **共振峰**：有聲格（自相關 F0 > 0、強度在最大值 25 dB 內）LPC（Praat Burg，5 個共振峰、上限 5,500 Hz、25 ms 窗）F1／F2 中位數；所有聲線用同一上限才可互相比較。兒童聲道短，F1／F2 一般高於成人；只是「像不像孩子」的代理指標。
- **eleven_v3 前兩名**：排名（客觀、依序比較）：① 兩個轉寫模型都在同一處出現非同音差異的台詞數（少者優先）→ ② 檢查詞「不一致」次數（兩個模型合計）→ ③ 各句 PER（兩個模型取小）的平均 → ④ 合併 F0 中位與 F0 目標相差的半音數。

- **「紙燈節」聲調**：定位：large-v3-turbo 轉寫加字級時間戳（faster-whisper word_timestamps），把轉寫逐字對齊到合成用文字，取「紙燈節」三個字的時間；再在這個時間窗（前後各放寬 80 ms）裡找 ≥50 ms 的有聲段（parselmouth 自相關，10 ms；音高範圍依該檔 F0 中位自動設定：下限 0.6 倍、上限 2 倍；高於中位 1.7 倍的格減半、低於 0.55 倍的格加倍，修正八度錯誤）：紙（zh）、燈（d）、節（j）的聲母都是清音，正好三段時直接用；多於三段時，每個字取與時間戳重疊最多的一段；少於三段（或某段有聲格不足 50 ms）時改用時間戳範圍內的有聲格。每個字：起點＝前 20% 有聲格中位數、終點＝後 20% 中位數、最低點＝三點移動中位數的最小值。判定：燈＝一聲（終點／起點 ≥ 0.90，沒有三聲、四聲那種明顯下降；且平均 F0 ≥ 紙的 1.05 倍，紙是三聲、接一聲時讀低的半三聲）；節＝二聲（終點／最低點 ≥ 1.08，且最低點落在前 70%；台灣華語二聲常是先略降再上揚）。另以同一聲線念「紙等街。」（燈三聲、節一聲＝使用者聽到的「只等街」）作對照。G3 tone_check_ting.json 的 0.95–1.05 高平門檻是單音節框句用的；本句「燈」夾在低的「紙」與「節」之間，edge 基準的「燈」也會上揚到 1.19，所以只要求「不下降且比紙高」。

## 5. 數據與檔案

- `samples/<角色>/<角色>__<聲線>_<模型>__<項目>.wav`：226 檔（edge 基準檔名為 `__edge__`）。
- `samples.json`：每檔的合成參數（voice_id、模型、speed、seed、合成用文字、分段、原始檔、母帶紀錄）。
- `metrics.json`：每檔全部量測與兩個模型的轉寫比對。
- `candidates.json`：每個角色的篩選條件、通過名單、候選、v2 排名、eleven_v3 前兩名與比較表數據。

- `voices.json`、`probe.json`、`previews.json`：聲線庫查詢、Starter 實測、預覽檔量測；`ledger.json`：本代理點數帳本。
- `listen.html`：選擇性試聽頁（相對路徑，直接用瀏覽器開）。
- `raw/`、`raw_edge/`、`previews/`：ElevenLabs／edge 原始檔與預覽檔。
- 重跑：`tools/.venv/bin/python tools/vo_el_library.py <discover|previews|probe|shortlist|render|v3|measure|tone|report>`（有快取，不重複計點）。

## 6. 未驗證項目

- 聽感：自然度、台灣口音自然度、情緒（阿樂困惑但咬字清楚、林老師肯定溫暖、邀請者友善不陰沉、陳伯伯渾厚讓人安心）、角色年齡感。
- 童聲像不像：只有 F0 與 F1／F2 代理指標；聲線庫都是成人聲線，ElevenLabs 沒有音高參數。
- 「和」念 hé 或 hàn、「一」「不」變調：轉寫看不出，未驗證。
- 邀請者「中性」：只用 F0 中性區（145–175 Hz）當條件，聽起來是否中性未驗證。
- 實際投影現場的音量、清晰度與學校筆電播放：未驗證（第 3 天彩排）。
- 授權條款：Starter 方案的商用／署名條件未在本輪查證（帳號方案條款由使用者確認）。
