# EL 選角：聲線設計驗收包（入口）

製作代理：配音製作（ElevenLabs 聲線設計）。腳本：`tools/vo_el_design.py`。本包只列候選與全部數據，**不含評分或推薦**；篩選只用下列客觀條件。聽感、台灣口音自然度、「像不像孩子」的聽覺判斷一律 **未驗證**（Claude 聽不到聲音）。

## 1. 方法

- 聲線設計：`POST /v1/text-to-voice/design`（`output_format=mp3_44100_128`、`seed=20261021`、`guidance_scale=5`、`loudness=0.5`、`should_enhance=false`）。描述：小晴、小宇、折折取 `audio/vo/design_specs.json`；品安依 `script/角色表_v03.md` 補寫（四個孩子中聲音最低、輕聲、慢）。預覽文字＝該角色劇本台詞串接（≥100 字元，套 `pronounce.json` 全域替身字，和正式管線相同），每次回傳 3 個預覽，全部量測。
- 描述被拒的處理（三層，全部記錄原文）：①原描述（寫兒童年齡）→ ②任務指定改寫「為兒童角色配音的年輕成人配音員，明亮、輕快、帶童聲質感的台灣華語」（英文版）→ ③代理新增：①②在 eleven_ttv_v3 與 eleven_multilingual_ttv_v2 都回 403 blocked_generation，第三層拿掉所有兒童字眼（child、children's、schoolgirl、childlike、nine-year-old），只描述音色（年輕成人女性、明亮／偏低、輕聲等）。三層全文見 candidates.json → design_specs。折折的原描述（摺紙貓主持人）沒有被擋。
- 模型：四個角色先用 eleven_ttv_v3；eleven_multilingual_ttv_v2 加試小晴（原意只是確認安全過濾是否同樣擋兒童描述，結果第三層通過而產生預覽）與折折（ttv_v3 三個預覽 F0 都低於 280 Hz、且原描述可用）。小宇、品安未加試 ttv_v2，以保留點數。
- edge-tts 基準：同一段文字，照 `audio/vo/casting.json` 目前參數（含 post 設定）以 `vo_build.render_line` 合成。
- 母帶處理同 G3：`vo_lib.master`（頭 120 ms、尾 250 ms、−18 LUFS、真峰值 ≤ −1.5 dBTP、48 kHz／16-bit／單聲道）。
- 量測同 G3：`vo_lib.measure`（響度、真峰值、削波、頭尾靜音、毛語速／淨語速、句中停頓、F0 中位數與 p10–p90），轉寫 `vo_lib.transcribe_compare`（small＋large-v3-turbo，逐字對齊＋台灣讀音表）。共振峰：Praat Burg 法 LPC，上限 6500 Hz（5500 Hz 版另列於 metrics.json）。
- 代表句：存好的聲線 × `eleven_multilingual_v2`（stability 0.5、similarity 0.75、style 0、speaker boost、speed 1.0）與 `eleven_v3`（stability 0.5、similarity 0.75、language_code zh），seed 20261021、mp3_44100_128；替身字版為主，另做原字對照句與短框句「紙燈節。」。

## 2. 客觀條件與篩選規則

- **per0**：轉寫：兩個轉寫模型（small、large-v3-turbo）中至少一個 PER＝0（per_min＝0；同 G3「兩個模型都出現的差異才算疑似讀音問題」）。小晴的預覽含人名「品安」，兩個模型在 G3 就把它寫成常用詞「平安」（review/G3/tone_check_pinan.json），所以 PER 另算「排除人名」版：轉寫裡的「平安」視為「品安」後重算；原始 PER 也列出。
- **check_words**：讀音檢查詞：兩個轉寫模型對每個檢查詞（vo_lib.CHECK_WORDS，含紙燈節、燈籠、折折、阿樂）都是「轉寫一致」或「同音轉寫」，沒有「不一致」。「一」「不」變調轉寫看不出，一律未驗證。
- **zdj_tone**：紙燈節聲調（折折必測；含「紙燈節」的檔都量）：有聲段與起訖量法同 review/G3/tone_check_ting.json；定位：large-v3-turbo 逐字時間與原文逐字對齊找出「燈」的時間，和它重疊最多的有聲段＝燈，前一段＝紙，後一段＝節（後面緊接、間隔 <80 ms 的段一併合併）；對齊失敗才退回「最後三個有聲段」並註明（第一版只用最後三個有聲段，複查時發現 zhezhe_ttv3_p2 的「節」被嘎裂聲切成兩段而錯位，故改法）。燈＝高平：終點／起點 0.93–1.07，且平均 F0 ≥ 1.08 × 紙的平均 F0；節＝上揚：終點／起點 ≥ 1.10。三項都成立才通過。
- **f0_target**：F0 中位數落在角色目標：小晴 245–275 Hz（約 260）、小宇 230–250 Hz、品安 180–200 Hz、折折 ≥280 Hz。
- **formants_higher**：共振峰：有聲段 F1 與 F2 中位數（Praat Burg 法 LPC，5 個共振峰、上限 6500 Hz、25 ms 窗，只取 F0>0 且強度在最大值 25 dB 內的格）都高於同一段文字的 edge 升調基準。
- **accent**：台灣口音、自然度、像不像孩子的聽感：無法量測，一律「未驗證」。

- 級別 1：全部條件成立（per0、check_words、zdj_tone〔折折〕、f0_target、formants_higher）
- 級別 2：除 f0_target 外全部成立（F0 不在目標內，依與目標的半音距離排序）
- 級別 3：check_words、zdj_tone〔折折〕、formants_higher 成立，但 PER≠0（依 PER、F0 距離排序）
- 選取：每個角色依（級別、F0 與目標的半音距離、F1×F2 相對 edge 的幾何平均倍率由高到低）排序。第 1 輪：每個角色取排序第一、級別 1–3 的候選；第 2 輪：各角色排序第二、級別 1–2 的候選依（級別、F0 距離）排序補到合計 6 個為止；每角色最多 2 個。沒有級別的候選不存。
