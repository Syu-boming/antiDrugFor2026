# 紙燈節｜反毒剪紙劇場

國小三、四年級、一節 40 分鐘的 2.5D 剪紙劇場（HTML＋three.js），主題「喪屍煙彈、毒駕」。教師用簡報筆逐步推進，八題三選一全班比手指作答。

**許博明老師製作**

- 線上版（預覽與練習）：https://syu-boming.github.io/antiDrugFor2026/
- 正式演出請用離線版：在 `app/` 執行 `npm install && npm run build`，產出 `app/dist/`（直接開 `index.html` 即可，不需網路）；Windows 可攜版用 `node electron/pack.mjs` 組裝。
- 教師資料：`teacher/pdf/`（講稿、操作卡、故障卡、題卡、教案、觀課導覽單等）；`node tools/teacher_docs.mjs` 重新產生。
- 製作規劃：`反毒剪紙劇場_課程與製作規劃_v1.3.md`；目前狀態 `PROJECT_STATE.md`；驗收紀錄 `REVIEW.md`。

## 隱私

程式不使用攝影機與麥克風、不辨識手勢、不蒐集姓名或使用紀錄；演出完全離線。

## 製作方式與授權

- 美術：Codex 圖像生成（ChatGPT 方案）與程式繪製；角色折折為程式幾何。
- 配音：ElevenLabs 語音合成（elevenlabs.io）。正式配音（`audio/vo/*_v04.wav`）在付費方案下以聲線庫聲線產生；ElevenLabs 已書面回覆同意兒童教育用途。G3 選角時期部分試音以 ElevenLabs 免費方案產生（Voice generated by ElevenLabs — elevenlabs.io），僅留在製作歷史中。
- 配樂與音效：自製（程式作曲，以 FluidR3_GM 音色庫算成音檔，MIT 授權，見 `audio/LICENSES/`；音效程式合成）。
- 程式庫：three.js（MIT）；Windows 可攜版使用 Electron（MIT，含 Chromium 授權檔）。建置會在 `app/dist/THIRD_PARTY_LICENSES.txt` 附上授權聲明。
- 字型：演出畫面使用系統字型；教師資料內嵌 Noto Sans TC（SIL OFL 1.1，`teacher/fonts/OFL.txt`）。
- 美術、配音與程式使用生成式 AI 工具輔助；內容經 AI 代理多輪檢核，演出前由教師實機彩排確認。
